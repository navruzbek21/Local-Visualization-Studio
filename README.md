# Visualization Studio

Локальная студия визуализации данных — аналог Flourish Studio, который работает **без интернета**:
внутри корпоративной сети, на сервере или прямо на рабочем компьютере. Графики строятся на
[Apache ECharts](https://echarts.apache.org); все библиотеки, шаблоны и карта мира лежат в проекте.

```
Корпоративная сеть ─► Веб-интерфейс (localhost / интранет)
                        ├─ Импорт данных: Excel, CSV, JSON, LAS, RSM (tNavigator/Eclipse), URL, SQLite / PostgreSQL / MySQL / MS SQL
                        ├─ Редактор: 30 шаблонов (54 варианта), в т.ч. 9 для разработки месторождений и таблица
                        └─ Экспорт: PNG / JPEG / SVG, автономный HTML, JSON-конфигурация ECharts, iframe
Внешний интернет ✕ не нужен
```

## Возможности

| **Разработка месторождений** | Профиль добычи, анализ падения добычи (Арпс), характеристики вытеснения, карта отборов и карта свойств пласта, планшет ГИС, торнадо-диаграмма, вероятностная оценка P90/P50/P10, диагностика обводнения по Чену, график Холла — подробнее [ниже](#для-инженера-по-разработке-месторождений). |
| **Аналитика** | Ящик с усами и скрипичная диаграмма, кросс-плот с регрессией (6 моделей, уравнение и R²), матрица корреляций и матрица диаграмм рассеяния, диаграмма Парето с ABC-анализом, график с несколькими осями Y (до пяти шкал) или панелями — подробнее [ниже](#аналитические-графики-и-несколько-осей-y). |

| **Шаблоны** | Столбчатая (рядом / накопление / 100%, вертикальная и горизонтальная), каскадная, радарная, линейный график и области, столбцы + линии, несколько осей Y, гонка столбцов (bar chart race), круговая / кольцевая / полукольцо / роза, древовидная карта, «солнечные лучи», воронка, точечная и пузырьковая, карта (хороплет и точки по координатам), тепловая карта, Санкей, спидометр / KPI, календарь, «свой код ECharts». |

Импорт CSV/TSV (автоопределение разделителя и кодировки, включая Windows-1251 из 1С), Excel (xlsx/xls/ods, выбор листа), JSON, LAS 2.0 (каротаж), RSM (сводка расчёта tNavigator / Eclipse), перетаскивание файла мышью. |

| **Предпросмотр** | По ширине окна, ноутбук, планшет, телефон. |
| **Экспорт** | PNG/JPEG (до 4×) и SVG любого размера, автономный HTML-файл (≈1,2 МБ, работает без сервера и интернета), конфигурация ECharts (option JSON), проект, данные CSV/JSON, iframe-код для встраивания в интранет-порталы. |

| **Свои карты** | Загрузите GeoJSON регионов, районов, зон обслуживания. Названия сопоставляются по любому свойству, с учётом частичных совпадений и кодов. |

## Для инженера по разработке месторождений

Шаблоны категории «Разработка месторождений» понимают типичные выгрузки: месячные эксплуатационные рапорты
(MER), сводки tNavigator/Eclipse (`.rsm`), каротаж (`.las`), таблицы из корпоративных БД. Колонки распознаются
по названиям — после загрузки файла график обычно строится без ручной настройки.

| Шаблон | Что показывает | Методика |
|---|---|---|
| **Профиль добычи** | Нефть, вода, жидкость, газ, закачка; обводнённость и давление на отдельной панели с общей осью времени; накопленная добыча; отметки ГТМ (ГРП, ЗБС…) | Объёмы за месяц пересчитываются в среднесуточные дебиты по календарным дням; переключатель скважин, «Всё месторождение» — сумма по датам; обводнённость — из сумм (в RSM доли переводятся в %) |
| **Анализ падения добычи** | Факт, аппроксимация, прогноз до экономического предела, EUR | Арпс: q(t) = qᵢ / (1 + b·Dᵢ·t)^(1/b); b подбирается автоматически (0 — экспоненциальная, 1 — гармоническая) по минимуму ошибки в логарифмах; окно аппроксимации — от максимума дебита или по датам; накопленная — по аналитическим формулам |
| **Характеристики вытеснения** | Интегральная зависимость, линия тренда, предельная точка; НИЗ, ОИЗ, КИН | Сазонов: Qн = a + b·ln Qж; Максимов: Qн = a + b·ln Qв; Назаров–Сипачёв: Qж/Qн = a + b·Qв (РД 153-39.0-110-01). Предел — по предельной обводнённости (по умолчанию 98%); аппроксимация на участке с обводнённостью выше порога или с заданной даты |
| **Карта отборов / свойства пласта** | Скважины по координатам: круговые диаграммы нефть/вода (размер — по жидкости), нагнетательные — треугольники; фоновая карта свойства с изолиниями | Интерполяция обратно взвешенных расстояний (IDW) с маской зоны влияния, изолинии методом «марширующих квадратов», равный масштаб по X и Y |
| **Планшет ГИС** | Каротажные кривые в дорожках с общей осью глубины, литология/пласты, отметки ВНК/ГНК/кровли | Сопротивления (RT, ILD, LLD, БК, ИК…) — логарифмическая шкала, нейтронная пористость — обратная; синхронная прокрутка глубины |
| **Торнадо-диаграмма** | Чувствительность NPV, запасов или добычи к параметрам | Отклонения от базового варианта, сортировка по размаху |
| **Вероятностная оценка** | Гистограмма реализаций, кривая вероятности превышения, P90/P50/P10 | Нефтегазовая конвенция (P90 — значение, превышаемое с вероятностью 90%) или статистическая |
| **Диагностика обводнения (Чен)** | ВНФ (WOR) и его производная ВНФ′ от времени в логарифмических координатах, отметка прорыва воды, подсказка по механизму обводнения | K. S. Chan, SPE 30775 (1995). ВНФ = вода / нефть (или из жидкости, или из обводнённости); производная — регрессия в скользящем окне; наклоны ВНФ и ВНФ′ на поздней стадии (вторая половина периода после прорыва по логарифму времени). Растущая ВНФ′ — признак прорыва по высокопроницаемому пропластку, снижающаяся — конуса подошвенной воды. Подсказка ориентировочная: проверяйте по ГИС и ПГИ |
| **График Холла** | Интеграл репрессии ∫(P − Pпл)dt от накопленной закачки, наклоны по участкам с изменением в %, производная Холла | H. N. Hall (1963); производная dH/d(ln W) — Izgec, Kabir (2009). Участки разделяются мероприятиями и датами; рост наклона — ухудшение приёмистости (кольматация, рост скин-фактора), снижение — ОПЗ, автоГРП или уход закачки. Пластовое давление — колонкой или константой (0 для модифицированного графика по устьевому давлению) |

Также полезны универсальные шаблоны: каскадная диаграмма (факторный анализ добычи), Санкей (баланс газа/жидкости),
солнечные лучи (структура фонда скважин), тепловая карта (обводнённость по скважинам и годам), гонка столбцов
(накопленная добыча), таблица (технологический режим, сводки) и аналитические графики ниже.

### Аналитические графики и несколько осей Y

| Шаблон | Для чего | Подробности |
|---|---|---|
| **Несколько осей Y** | Режим скважины: дебиты, обводнённость, давление, газовый фактор, штуцер на одном графике | До пяти шкал: колонки назначаются на «Ось Y 1 … 5» на вкладке «Данные» (по названиям — автоматически: дебиты → 1, обводнённость → 2, давление → 3, газовый фактор → 4). У каждой оси — название, единицы, вид (линии, области, столбцы, точки, ступени), сторона, мин/макс, логарифм, «от нуля». Режим «Панели» — каждая шкала отдельным графиком с общей осью X; на узком экране включается сам. Ось окрашивается в цвет серии, только если серия на ней одна |
| **Ящик с усами** | Разброс по группам: проницаемость по пластам, дебиты по скважинам, выбросы | Усы: 1,5 межквартильного размаха (Тьюки), мин–макс, P10–P90, P5–P95; среднее арифметическое или геометрическое; логарифмическая шкала (статистика считается по логарифмам); варианты «с точками», «скрипичная» (ядерная оценка плотности), горизонтальный |
| **Кросс-плот с регрессией** | Пористость — проницаемость, дебит — толщина и т.п. | Вариант точечной диаграммы: линейная, экспоненциальная, степенная, логарифмическая, полиномы 2-й и 3-й степени; отдельно по группам; уравнение, R² и n на графике (для экспоненциальной и степенной R² — по логарифмам, как в Excel) |
| **Матрица корреляций** | Какие параметры связаны | Пирсон или Спирмен, попарное исключение пропусков, незначимые связи (p ≥ 0,05, преобразование Фишера) приглушены, группировка связанных параметров (иерархическая кластеризация); вариант — матрица диаграмм рассеяния с гистограммами и автоматической логарифмической шкалой для асимметричных параметров |
| **Диаграмма Парето** | Причины потерь, простоев, отказов; вклад скважин в добычу | Сортировка по убыванию, накопленная доля, порог 80%, ABC-анализ, объединение мелких категорий в «Прочие» |

Несколько шкал на одном графике легко прочитать неверно: при трёх и более шкалах обычно нагляднее панели.

## Быстрый старт

Нужен **Node.js 22.13 или новее** (в нём есть встроенный SQLite). Других программ не требуется.

```bash
node server.js
```

Откройте http://localhost:3700 . На Windows можно запустить `start.bat`, на Linux/macOS — `./start.sh`.

## Установка в закрытой сети (без интернета)

Всё, что нужно для работы, уже лежит в папке `public/vendor` и `public/maps`. Серверу для работы нужен
только Node.js — `npm install` на целевой машине **не обязателен**.

1. На компьютере с доступом в интернет (один раз):
   ```bash
   npm install                 # библиотеки + драйверы PostgreSQL / MySQL / MS SQL
   npm run prepare-offline     # обновить public/vendor и public/maps из node_modules
   npm prune --omit=dev        # убрать то, что нужно только для сборки (необязательно)
   ```
2. Скопируйте папку целиком в закрытую сеть (архив, общий диск).
   Если на целевой машине нет Node.js — положите портативный Node.js в подпапку `node/`
   (`node/node.exe` для Windows, `node/bin/node` для Linux) — `start.bat` / `start.sh` найдут его сами.
3. Запустите `start.bat` или `./start.sh`.

Папка `node_modules` нужна только для драйверов PostgreSQL / MySQL / MS SQL. Без неё студия работает
полностью, кроме этих типов подключений (SQLite остаётся).

### Доступ коллегам по сети

По умолчанию сервер слушает только `127.0.0.1` (этот компьютер). Для доступа из интранета:

```bash
HOST=0.0.0.0 AUTH_USER=analytics AUTH_PASS='длинный-пароль' node server.js
```

На Windows (cmd): `set HOST=0.0.0.0` и т.д. перед `node server.js`.

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `PORT` | `3700` | Порт веб-интерфейса |
| `HOST` | `127.0.0.1` | `0.0.0.0` — доступ из сети |
| `DATA_DIR` | `./data` | Где хранить проекты, миниатюры, подключения, карты |
| `AUTH_USER`, `AUTH_PASS` | — | Пароль на вход (HTTP Basic). Рекомендуется при `HOST=0.0.0.0` |

Для HTTPS поставьте перед студией корпоративный обратный прокси (nginx, IIS, Apache) — сама студия
отдаёт HTTP.

### Запуск как службы

**Linux (systemd)** — `/etc/systemd/system/vstudio.service`:

```ini
[Unit]
Description=Visualization Studio
After=network.target

[Service]
WorkingDirectory=/opt/visualization-studio
ExecStart=/usr/bin/node server.js
Environment=HOST=0.0.0.0 PORT=3700 AUTH_USER=analytics AUTH_PASS=change-me
Restart=on-failure
User=vstudio

[Install]
WantedBy=multi-user.target
```

**Windows** — через [NSSM](https://nssm.cc): `nssm install VStudio "C:\vstudio\node\node.exe" server.js`,
рабочая папка `C:\vstudio`, переменные окружения — на вкладке *Environment*.

## Работа с данными

* **Форматы файлов:** `.csv .tsv .txt` (разделитель `, ; Tab |` и кодировка UTF-8 / Windows-1251 / KOI8-R / DOS-866
  определяются автоматически, можно выбрать вручную), `.xlsx .xls .xlsm .ods` (с выбором листа), `.json`
  (массив объектов, массив массивов, `{columns, rows}`, GeoJSON → таблица свойств), `.sqlite .db` (подключается как база).
* **Числа** понимаются в русском и английском формате: `1 234,56`, `1,234.56`, `12,5%`, `100 руб.`, `(150)` — отрицательное.
* **Даты:** `2024-03-15`, `15.03.2024`, `2024-03`.
* **LAS 2.0** (каротаж): кривые с единицами (`GR, GAPI`), значения NULL (−999.25) → пусто, поддерживается режим WRAP.
* **RSM** (tNavigator, Eclipse): страницы «SUMMARY OF RUN» склеиваются в одну таблицу; колонки называются
  `WOPR:P1, SM3/DAY`; множители `*10**3` применяются; даты `1-JAN-2020` → `2020-01-01`.
* **Базы данных:** «Данные» → «Из базы данных». Для SQLite укажите путь к файлу на сервере или загрузите файл.
  Для серверных СУБД — адрес, базу, пользователя. Запросы выполняются **только на чтение**: SQLite открывается
  в режиме read-only, PostgreSQL и MySQL — в `READ ONLY` транзакции, для MS SQL дополнительно блокируются
  изменяющие команды. Лучше всего создать отдельного пользователя с правами `SELECT`.
  Пароли хранятся на сервере в `data/connections.json` (права доступа 600) и не передаются в браузер.
* **Обновление:** если данные пришли из БД или по ссылке, на вкладке «Данные» есть кнопка «Обновить».

## Свои шаблоны графиков

Положите `.js`-файл в папку `templates/` рядом с `server.js` и обновите страницу. Пример с подробными
комментариями — [`templates/calendar.js`](templates/calendar.js) (календарная тепловая карта).

```js
VS.registerTemplate({
  id: 'my-chart', name: 'Мой график', category: 'Сравнение', icon: '<svg viewBox="0 0 48 36">…</svg>',
  bindings: [
    { key: 'label', name: 'Категории', dataType: 'any' },
    { key: 'values', name: 'Значения', dataType: 'number', multiple: true },
  ],
  sections: [{ id: 'main', title: 'Мои настройки', items: [
    { key: 'my.smooth', label: 'Сглаживание', type: 'toggle', default: true },
  ] }],
  sample: { data: [['Категория', 'Значение'], ['А', 10], ['Б', 20]], bindings: { label: 0, values: [1] } },
  build(ctx) {
    const label = ctx.column('label');
    return {
      xAxis: VS.axis(ctx, 'x', { type: 'category', data: label.raw }),
      yAxis: VS.axis(ctx, 'y', { type: 'value' }),
      grid: VS.grid(ctx),
      series: ctx.columnsOf('values').map((c, i) => ({ type: 'line', name: c.name, data: c.num, smooth: ctx.s['my.smooth'], color: ctx.color(c.name, i) })),
    };
  },
});
```

Типы настроек: `text`, `textarea`, `number`, `range`, `toggle`, `select`, `radio`, `color`, `palette`, `scale`, `code`, `heading`.
Поле `match` у привязки (регулярное выражение или список) включает автопривязку колонки по названию — готовые
шаблоны отраслевых названий доступны в `VS.petroPatterns` (нефть, вода, жидкость, газ, закачка, обводнённость,
давление, скважина, дата, координаты, глубина). Шаблон без ECharts (как «Таблица») объявляет `renderHtml()` и
`drawStatic()` вместо `build()`.
Заголовки, источник, легенда, подсказки, формат чисел, анимация и фильтр добавляются к шаблону автоматически.

Для разовых задач без файла есть шаблон **«Свой код ECharts»**: в настройках пишется функция,
которая получает данные таблицы и возвращает `option` для ECharts.

## Свои карты

«Источники и карты» → «Загрузить GeoJSON» (или прямо в настройках шаблона «Карта»). Подойдёт
`FeatureCollection` с координатами WGS84. Shapefile, KML и т.п. конвертируются в GeoJSON в QGIS
(«Экспорт → Сохранить объекты как → GeoJSON»). TopoJSON нужно предварительно сохранить как GeoJSON.

## Безопасность

* По умолчанию студия доступна только с этого компьютера (`HOST=127.0.0.1`). Открывая доступ в сеть,
  задайте `AUTH_USER` / `AUTH_PASS` и по возможности HTTPS через обратный прокси.
* Все пользователи с доступом к студии видят и могут менять все проекты — это общая рабочая область команды.
* Шаблон «Свой код ECharts» и HTML в «Своём шаблоне подсказки» выполняются в браузере у каждого, кто
  открывает визуализацию. Значения из таблиц экранируются, но сам код автора — нет, поэтому доступ к
  студии стоит давать только доверенным сотрудникам.
* Подключения к БД — только чтение; используйте учётные записи с правами `SELECT`.
* «Загрузка по ссылке» выполняется сервером студии: он может обращаться к ресурсам интранета,
  доступным ему самому (адреса link-local / метаданных заблокированы).
